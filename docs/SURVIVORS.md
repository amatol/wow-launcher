# Отдельный режим Warcraft Survivors

Источник: AdamMcWilliam/warcraft-survivors, ветка survivors,
ревизия 7c6c848d5c78e2adeaaf9f3b7715fe106e2c0a98.

Windows EXE собирается вручную workflow survivors.yml с закреплёнными
Cargo.lock и Rust 1.98.1, без dev-функций. Ресурсы интерфейса включены
в бинарник upstream. Клиентские данные нужны от английского WoW 1.12.1
build 5875; данные WotLK не используются.

Интеграция: отдельная кнопка, запрос действующих логина и пароля,
проверка SRP6 через существующий authserver; отдельный каталог установки,
проверка SHA-256 файлов и локальные настройки. Пароль не сохраняется.
Синхронизации прогресса и игрового сервера для режима нет.

Исходный автономный EXE допускает запуск без лаунчера. Проверка аккаунта
защищает штатный путь запуска Dreamworld, не является DRM.

## Установка и запуск

Кнопка «Warcraft Survivors» доступна независимо от установки WotLK.
«Войти и играть» проверяет аккаунт на wotlk.amatol.blog:3724 (WoW 3.3.5a,
SRP6, включая доказательство сервера M2), загружает отдельный манифест
/launcher/survivors/manifest.json и устанавливает только разрешённые файлы
в Survivors рядом с Dreamworld.exe. Во время долгой установки
аккаунт проверяется повторно перед запуском. Поддерживается код TOTP.
Штатный authserver учитывает вход и блокировки так же, как для WoW.

Файлы режима имеют обязательные размер и SHA-256; отдельные файлы загружаются
по HTTPS с нашего сервера, базовый ZIP для первой установки — с Яндекс Диска.
Частичные загрузки сохраняются по хэшу, продолжаются
с проверкой Content-Range, файл заменяется только после полной проверки.
Ссылки/junction из каталога режима наружу запрещены. WotLK и его сохранения
не меняются. Локальные настройки режима разделены по хэшу имени аккаунта
в Survivors/profiles. Пароль и код аутентификатора не сохраняются
в настройках и не передаются процессу игры; вывод игры — survivors.log.

Режим не подключается к worldserver, не синхронизирует прогресс и не влияет
на онлайн персонажей. Исходный игровой интерфейс пока английский.
Windows-сборка поддерживает видеокарты, совместимые с wgpu/Bevy 0.18;
полноценный графический запуск необходимо проверить на компьютере игрока.

## Опубликованный выпуск 20261021

19 файлов, 5539091176 байт (около 5.5 ГБ), включая app-local VCRUNTIME140.dll.
Пофайловая установка требует около 6 ГБ свободного места; установка
из ZIP требует дополнительного места под архив (см. ниже). Системные службы и
клиент WotLK не обновляются. Вход использует текущие аккаунты и их блокировки.
Полная Windows CI-проверка загружает все данные и запускает только меню;
физическая GPU и полноценное прохождение остаются проверкой на компьютере игрока.

## Папка Survivors и перенос прежней установки

Лаунчер 20261022 использует папку Survivors. Если существует прежняя
WarcraftSurvivors, вся папка переименовывается без копирования: игровые
архивы, профили и .downloads остаются на месте, частичная загрузка
продолжается по Range. Перед обновлением закройте прежний лаунчер и игру.
Если обе папки уже содержат данные, автоматический перенос останавливается
с сообщением, сохраняя обе папки; неизвестные файлы не заменяются.

По прямому разрешению владельца от 21.10.2026 этот выпуск опубликован
с версией следующего дня 20261022 для штатного автообновления версии 20261021.
Это разовое исключение из датирования по фактическому дню публикации.


## Первоначальная установка с Яндекс Диска

С версии 20261023 для пустой установки загружается
[Survivors.zip](https://disk.yandex.ru/d/fxffTTHSeFgrgg) (5409017337 байт).
ZIP и все игровые файлы проверяются по SHA-256. Архив распаковывается
в папку Survivors рядом с Dreamworld.exe; вложенная папка из архива
не создаёт Survivors/Survivors. Профили, журналы, прежняя .version и
посторонние исполняемые файлы из архива не устанавливаются.

Для первой установки требуется место одновременно для ZIP и распакованных
файлов — около 10,4 ГиБ. При обрыве сохраняется .downloads/<SHA-256>.part,
следующий запуск продолжает загрузку по HTTP Range. После отмены распаковки
сохраняется проверенный ZIP; повторный запуск использует его снова.
Архив удаляется после успешной установки и проверки актуальности.

Если игровые файлы или их пофайловые .part уже существуют, используется
прежняя проверка и докачка недостающих файлов с сервера. Обновления после
распаковки также загружаются с сервера: базовый ZIP не требуется пересобирать
при каждом обновлении игры. Пользовательские профили сохраняются.

При замене архива на Яндекс Диске нужно проверить состав и обновить
SURVIVORS_ARCHIVE_SIZE/SURVIVORS_ARCHIVE_SHA256 в config.py, затем собрать
новый лаунчер. Публичная ссылка хранится в SURVIVORS_ARCHIVE_PUBLIC_URL.
Проверка полного сценария на Windows: workflow verify-survivors-yandex.yml;
она использует tools/verify_survivors_yandex.py без паролей игроков.
