# Состояние Dreamworld Launcher

Последнее обновление: 2026-07-31

## Цель

Подготовить Windows-лаунчер Dreamworld и HTTPS-сервер обновлений для игрового
сервера AzerothCore из `/root/wowserver`, сохранив безопасную границу с
Telegram-ботом из `/root/telegrambot`.

## Постоянные решения

- Лаунчер называется `Dreamworld.exe`.
- Игровой клиент запускается только через `Wow.exe` (допустимы варианты
  регистра имени файла).
- Публичная база обновлений:
  `https://wotlk.amatol.blog/launcher/`.
- Эталонный клиент находится в `/opt/azerothcore/client`; файлы клиента не
  добавляются в Git.
- Публичная раздача хранится отдельно в `/srv/dreamworld-launcher`.
- Раздача обновлений статическая и не имеет доступа к MySQL, AzerothCore SOAP
  или локальному API Telegram-бота.
- Версии лаунчера и клиента имеют формат `YYYYMMDD`.
- Сначала публикуются файлы, затем манифест: манифест является последним
  атомарным шагом выпуска.

## Ближайшие шаги

1. Отправить локальные коммиты в GitHub, дождаться Windows CI и скачать
   `Dreamworld.exe`.
2. Создать и опубликовать `launcher_manifest.json`, проверить HTTPS и
   самообновление на Windows.
3. Проверить установку/обновление на чистой Windows-папке клиента.
4. При необходимости передать ссылку на лаунчер в Telegram-бот.

## Важные ограничения

- Не публиковать фиктивные или пустые рабочие манифесты.
- Не добавлять клиент WoW, сборочные артефакты, сертификаты и секреты в Git.
- Не открывать наружу `127.0.0.1:7878` (SOAP), `127.0.0.1:8080` (Dreamworld
  API) и MySQL.
