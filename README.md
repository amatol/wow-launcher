# WoW Launcher

Простой графический лаунчер для обновления клиента **World of Warcraft** (приватный сервер, 1.12 / 3.3.5a и т.д.).

Лаунчер обновляет файлы клиента в **папке, из которой он запущен**.

## Возможности

- **GUI на PyQt5** — тёмная тема, прогресс-бар, лог-консоль
- **HTTP/FTP обновление** — скачивает файлы из манифеста, проверяет SHA-256
- **BitTorrent фолбэк** — если HTTP недоступен, переключается на торрент
- **Манифест-система** — JSON с описанием версий и файлов
- **Точечная проверка** — качает только изменившиеся файлы (по размеру/хэшу)
- **Кнопка «Играть»** — запускает `Wow.exe` из папки лаунчера

## Структура

```
wow-launcher/
├── main.py                 # точка входа
├── config.py               # конфигурация (пути, URL, таймауты)
├── manifest.json           # пример манифеста обновлений
├── requirements.txt
├── core/
│   ├── version.py          # проверка/запуск Wow.exe
├── updater/
│   ├── manifest.py         # парсинг манифеста, проверка хэшей
│   ├── http_updater.py     # HTTP-скачивание с проверкой SHA-256
│   └── torrent_updater.py  # BitTorrent фолбэк (libtorrent)
└── ui/
    ├── main_window.py      # главное окно
    └── widgets.py          # лог-консоль, прогресс-бар
```

## Установка

### Требования

- Python 3.8+
- Windows (для запуска `Wow.exe`; лаунчер работает и на Linux/macOS, но запуск клиента — через `subprocess`)

### Установка зависимостей

```bash
pip install -r requirements.txt
```

> **libtorrent**: для работы торрент-фолбэка нужен `libtorrent-rasterbar`.
> Установка на Windows: `pip install libtorrent-rasterbar` (или скачать wheel с [PythonLibtorrent](https://github.com/arvidn/libtorrent/releases)).
> Если libtorrent не установлен — HTTP-обновление работает, торрент-фолбэк отключается.

## Запуск

Поместите `main.py` (или собранный `.exe`) в папку с клиентом WoW, затем:

```bash
python main.py
```

## Настройка

### URL манифеста

В кнопке **«Настройки»** можно изменить URL манифеста обновлений.
Или отредактируйте `config.py`:

```python
MANIFEST_URL = "https://your-server.com/wow/manifest.json"
```

### Формат манифеста

См. пример `manifest.json`:

```json
{
  "version": "3.3.5a-r1",
  "files": [
    {
      "path": "Wow.exe",
      "size": 10485760,
      "sha256": "e3b0c44298fc1c149...",
      "http_url": "https://.../Wow.exe",
      "torrent_url": "https://.../Wow.exe.torrent"
    }
  ]
}
```

| Поле         | Описание                                      |
|--------------|-----------------------------------------------|
| `version`    | Версия патча. Если отличается — качаем всё.   |
| `path`       | Относительный путь внутри папки клиента       |
| `size`       | Размер в байтах (0 — пропустить проверку)    |
| `sha256`     | SHA-256 хэш файла (пустая строка — пропустить)|
| `http_url`   | URL для HTTP-скачивания                       |
| `torrent_url`| URL `.torrent`-файла (опционально)            |

## Как это работает

1. Лаунчер определяет свою папку как папку клиента (`Config.GAME_DIR`)
2. Ищет `Wow.exe` в этой папке
3. Качает манифест с `MANIFEST_URL`
4. Сравнивает версию манифеста с локальной (`.launcher_version`)
5. Определяет нужные файлы (версия отличается или хэш не совпадает)
6. **Пытается HTTP** → если не удалось → **BitTorrent**
7. Проверяет SHA-256 каждого скачанного файла
8. Создаёт бэкап существующего файла (`.bak`) перед заменой
9. После успеха — записывает новую версию
10. Кнопка «Играть» запускает `Wow.exe`

## Сборка в .exe (опционально)

```bash
pip install pyinstaller
pyinstaller --onefile --windowed main.py
```

Скопируйте `main.exe` из `dist/` в папку клиента.
