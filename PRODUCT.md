# Dreamworld Launcher

<!-- impeccable:product-schema 1 -->

## Платформа и стек

Настольное приложение Windows, Python 3.10+, PyQt5. Локальная headless-проверка
на Linux; сборка Windows EXE штатным GitHub Actions и PyInstaller.

## Пользователь и задача

Игрок сервера Dreamworld устанавливает, обновляет и запускает клиент WoW,
читает новости, выбирает аддоны, переходит в Telegram для управления аккаунтом.

## Подтверждённые ограничения

- Название окна: Wrath of the Lich King AI Launcher; файл: Dreamworld.exe.
- Запускается Wow.exe из папки лаунчера. SHA-256 и безопасная установка сохраняются.
- 1000×560 по умолчанию, минимум 720×400; системное масштабирование Qt.
- Один опубликованный выпуск лаунчера в день, версия YYYYMMDD по Москве.
- Новостей не более пяти, источник — опубликованный news.json.
- Пользователь 27.09.2026 подтвердил направление «Атмосфера WotLK».
- Статус доступности игрового сервера не измеряется: не показывать выдуманный онлайн.

## Источники фактов

README.md, AGENTS.md, config.py, существующие обработчики ui/main_window.py,
публичные новости и манифест аддонов. Скриншоты с имитацией загрузки — проверочные,
не доказательство фактической загрузки клиента или работы игры на Windows.
