# Отдельный режим Warcraft Survivors

Источник: AdamMcWilliam/warcraft-survivors, ветка survivors,
ревизия 7c6c848d5c78e2adeaaf9f3b7715fe106e2c0a98.

Windows EXE собирается вручную workflow survivors.yml с закреплёнными
Cargo.lock и Rust 1.98.1, без dev-функций. Ресурсы интерфейса включены
в бинарник upstream. Клиентские данные нужны от английского WoW 1.12.1
build 5875; данные WotLK не используются.

Интеграция: отдельная кнопка, запрос действующих логина и пароля,
проверка SRP6 через существующий authserver; отдельный каталог установки,
проверка SHA-256 файлов и локальные настройки. Пароль не сохраняется.
Синхронизации прогресса и игрового сервера для режима нет.

Исходный автономный EXE допускает запуск без лаунчера. Проверка аккаунта
защищает штатный путь запуска Dreamworld, не является DRM.

## Установка и запуск

Кнопка «Warcraft Survivors» доступна независимо от установки WotLK.
«Войти и играть» проверяет аккаунт на wotlk.amatol.blog:3724 (WoW 3.3.5a,
SRP6, включая доказательство сервера M2), загружает отдельный манифест
/launcher/survivors/manifest.json и устанавливает только разрешённые файлы
в WarcraftSurvivors рядом с Dreamworld.exe. Во время долгой установки
аккаунт проверяется повторно перед запуском. Поддерживается код TOTP.
Штатный authserver учитывает вход и блокировки так же, как для WoW.

Файлы режима имеют обязательные размер и SHA-256; источником служит только
HTTPS на нашем сервере. Частичные загрузки сохраняются по хэшу, продолжаются
с проверкой Content-Range, файл заменяется только после полной проверки.
Ссылки/junction из каталога режима наружу запрещены. WotLK и его сохранения
не меняются. Локальные настройки режима разделены по хэшу имени аккаунта
в WarcraftSurvivors/profiles. Пароль и код аутентификатора не сохраняются
в настройках и не передаются процессу игры; вывод игры — survivors.log.

Режим не подключается к worldserver, не синхронизирует прогресс и не влияет
на онлайн персонажей. Исходный игровой интерфейс пока английский.
Windows-сборка поддерживает видеокарты, совместимые с wgpu/Bevy 0.18;
полноценный графический запуск необходимо проверить на компьютере игрока.

## Опубликованный выпуск 20261021

19 файлов, 5539091176 байт (около 5.5 ГБ), включая app-local VCRUNTIME140.dll.
Начальная установка требует около 6 ГБ свободного места. Системные службы и
клиент WotLK не обновляются. Вход использует текущие аккаунты и их блокировки.
Полная Windows CI-проверка загружает все данные и запускает только меню;
физическая GPU и полноценное прохождение остаются проверкой на компьютере игрока.
